01
// 01 ARSITEKTUR SISTEM

Apa itu Linux?

Linux sebenarnya adalah kernel, yaitu inti yang mengatur perangkat keras seperti prosesor, memori, dan disk. Kernel ini digabung dengan perangkat lunak lain (GNU, desktop, aplikasi) menjadi paket lengkap yang disebut distribusi atau distro.

Kodenya terbuka: siapa pun boleh membaca, mengubah, dan membagikannya. Itu sebabnya ada ratusan distro dengan tujuan berbeda-beda.

1. Aplikasi Pengguna (Userland)
Level 4

Browser internet, pengolah kata LibreOffice, editor kode, pemutar musik, serta ribuan perangkat lunak bebas lainnya.

2. Shell & Desktop Environment
Level 3

Antarmuka visual dan baris perintah (Bash, Zsh, GNOME, KDE Plasma) yang menerjemahkan instruksi pengguna ke sistem.

3. Kernel Linux (Inti Sistem)
Jantung OS

Pusat kendali utama: mengatur alokasi prosesor (CPU), manajemen memori RAM, jadwal tugas, dan komunikasi driver hardware.

4. Perangkat Keras (Hardware)
Fisik

Komponen fisik komputer: Processor x86/ARM/RISC-V, kartu grafis, memori, penyimpanan SSD/HDD, dan kartu jaringan.

02
// 02 KRONOLOGI EVOLUSI

Perjalanan singkat

1991
Linus Torvalds, mahasiswa Finlandia, mengumumkan kernel buatannya sebagai proyek hobi.
1992
Linux dirilis dengan lisensi GNU GPL, sehingga bebas dipakai dan dikembangkan bersama.
1993
Debian dan Slackware lahir, distro tertua yang masih dipakai sampai sekarang.
2004
Ubuntu hadir dan membuat Linux ramah bagi pengguna desktop biasa.
2008
Android, yang berbasis kernel Linux, dirilis dan menyebar ke miliaran ponsel.
03
// 03 DISTRIBUSI

Pilih distro

Tidak ada distro terbaik, hanya yang paling cocok. Ketuk untuk melihat.

RAMAH PEMULA

Ubuntu

Kategori: Pemula

Paling populer untuk desktop. Pembaruan teratur, komunitas besar, dan banyak tutorial berbahasa Indonesia.

Cocok untuk: pengguna baru, kantor, belajar.
PINDAHAN WIN

Linux Mint

Kategori: Pindahan dari Windows

Tampilannya akrab dengan menu di kiri bawah. Langsung siap pakai, termasuk codec media.

Cocok untuk: laptop lama dan pengguna yang ingin mudah.
CUTTING-EDGE

Fedora

Kategori: Terbaru

Memakai teknologi terbaru lebih dulu, dengan dukungan kuat dari Red Hat.

Cocok untuk: pengembang yang ingin software mutakhir.
SOLID ROCK

Debian

Kategori: Stabil

Dikenal sangat stabil dan menjadi dasar banyak distro lain, termasuk Ubuntu.

Cocok untuk: server dan sistem yang tak boleh sering rusak.
ROLLING RELEASE

Arch Linux

Kategori: Mahir

Dipasang dari nol dan disusun sendiri. Dokumentasinya (ArchWiki) sangat lengkap.

Cocok untuk: yang ingin paham isi sistem dan kontrol penuh.

// 04 TERMINAL WORKFLOW

Perintah dasar

Daftar perintah interaktif ala Command Palette. Gunakan pencarian atau tombol panah keyboard.

ESC untuk reset
pwd Menampilkan folder tempat kamu berada
ls Melihat isi folder
cd folder Pindah ke folder lain
mkdir nama Membuat folder baru
cp a b Menyalin berkas a menjadi b
mv a b Memindahkan atau mengganti nama berkas
rm berkas Menghapus berkas (tidak masuk tempat sampah)
man perintah Membuka panduan lengkap sebuah perintah
sudo Menjalankan perintah dengan hak admin
