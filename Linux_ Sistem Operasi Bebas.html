Apa itu Linux?

Linux sebenarnya adalah kernel, yaitu inti yang mengatur perangkat keras seperti prosesor, memori, dan disk. Kernel ini digabung dengan perangkat lunak lain (GNU, desktop, aplikasi) menjadi paket lengkap yang disebut distribusi atau distro.

Kodenya terbuka: siapa pun boleh membaca, mengubah, dan membagikannya. Itu sebabnya ada ratusan distro dengan tujuan berbeda-beda.

1. Aplikasi Pengguna (User Space) Browser, LibreOffice, Pemutar Media, Text Editor, Game
Software
2. Shell & Desktop Environment Bash, Zsh, GNOME, KDE Plasma, XFCE (Antarmuka & Terminal)
Interface
3. Kernel Linux (Inti Sistem) Manajemen memori, prosesor (CPU), jadwal proses, driver perangkat keras
Jantung OS
4. Perangkat Keras (Hardware) CPU, RAM, Hard Disk/SSD, Kartu Grafis, Keyboard, Jaringan
Fisik

Perjalanan singkat

  • 1991 Linus Torvalds, mahasiswa Finlandia, mengumumkan kernel buatannya sebagai proyek hobi.
  • 1992 Linux dirilis dengan lisensi GNU GPL, sehingga bebas dipakai dan dikembangkan bersama.
  • 1993 Debian dan Slackware lahir, distro tertua yang masih dipakai sampai sekarang.
  • 2004 Ubuntu hadir dan membuat Linux ramah bagi pengguna desktop biasa.
  • 2008 Android, yang berbasis kernel Linux, dirilis dan menyebar ke miliaran ponsel.

Perintah dasar

Berikut kumpulan perintah terminal penting yang sering digunakan pengguna Linux sehari-hari:

Perintah Fungsi Aksi
pwd Menampilkan folder tempat kamu berada
ls Melihat isi folder
cd folder Pindah ke folder lain
mkdir nama Membuat folder baru
cp a b Menyalin berkas a menjadi b
mv a b Memindahkan atau mengganti nama berkas
rm berkas Menghapus berkas (tidak masuk tempat sampah)
man perintah Membuka panduan lengkap sebuah perintah
sudo Menjalankan perintah dengan hak admin

Kenapa orang memakai Linux

Gratis

Tanpa biaya lisensi, dan boleh dipasang di berapa pun komputer.

Ringan

Banyak distro berjalan lancar di laptop lama yang sudah berat memakai sistem lain.

Aman

Pengelolaan izin yang ketat dan pembaruan cepat dari komunitas.

Bisa diubah

Tampilan, perilaku, sampai kernelnya bisa disesuaikan sesuai selera.
